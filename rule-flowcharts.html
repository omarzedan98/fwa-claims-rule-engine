C1Duplicate Claim

Two or more claims for the same patient on the same day billing exactly the same set of services.

Level
Claim
Key settings
Consultation lines include the physician, so the same code by two doctors is not a duplicate. The lowest claim ID is treated as the original.
Reference data
None

C3Cloned Claims

The same provider, anywhere in the file, billing an identical set of services, principal diagnoses and chief complaint for different patients.

Level
Claim
Key settings
No month limit: copies months apart still match. Every claim in a cloned set is reported (a pair gives 2, a set of 3 gives 3), because no patient's claim can be treated as the genuine one. Secondary diagnoses are not compared.
Reference data
None

S1Duplicate Service

The same service billed more than once for the same patient on the same day.

Level
Service line
Key settings
Two keys, both with the tooth number: blank on both lines for non-dental work, so it drops out. Non-consultation lines are compared across service types, so dental work typed SRVS is keyed by tooth too. For consultations the cheapest line is kept and the dearer ones are reported.
Reference data
None

S17-1Therapeutic Duplication, Same Active Ingredient

Two different drugs given to one patient on one day that share the ATC code to 7 characters (same active ingredient).

Level
Service line
Key settings
Each pair is charged to its deepest matching level only. The same service code twice is left to S1. The cheapest line of a group is kept as the legitimate treatment.
Reference data
SFDA drug list: AtcCode1 (by RegisterNumber, then GTIN)

S19-1Service Too Frequent Use, Provider Level

A service or drug that appears on more than 70% of a provider's claims, consultation excluded.

Level
Service line
Key settings
Counted by distinct claim ID. An unlisted, placeholder or blank NPHIES code is judged by the line's service code instead. Exactly 70% does not fire.
Reference data
SBS and NPHIES GTIN: Unlisted (to spot non-specific codes)

S20-2Missed Chief Complaint

A paid line on a claim with no chief complaint, or one holding no real word.

Level
Service line
Key settings
A real word is any run of 2+ letters (Latin or Arabic), so "htn" passes and "0", ".", "s" do not. If the file has no complaint column at all, the rule stays silent.

S22Excessive Member Visits

A patient with more than 5 visit days inside a rolling 30 days, counted across every provider and service type.

Level
Service line
Key settings
A visit day is one patient on one date; same-day claims count once. The window is that day and the 29 before it. Threshold set from the data with Tukey's outlier fences. Treatment courses (dressings, injections, physiotherapy) are not excluded. Lines S2 or S11 already reported are skipped, but still count as visits.
Reference data
None
